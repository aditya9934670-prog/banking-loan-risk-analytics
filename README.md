# Banking Customer & Loan Portfolio Risk Analytics

I'm a Computer Science student preparing for data analyst roles. This is my project on bank loan data, where I'm practising SQL, Python and Excel on a realistic finance problem.

## What I want to find out
- How many loans are issued each month, and for how much?
- How much of the money lent has been paid back?
- Which borrower groups (loan grade, home ownership, employment length, loan purpose) have more charged-off loans?

## Tools
- **Python** (Pandas, Matplotlib, Seaborn): cleaning the data and exploring it
- **SQL** (SQLite): writing queries to answer business questions
- **Excel**: PivotTables, charts and a dashboard
